# Bluestock Mutual Fund Analytics Capstone

## Overview

This project analyzes mutual fund performance, investor behavior, SIP trends, portfolio concentration, and industry growth using Python, SQL Server, and Tableau.

## Technologies Used

* Python
* Pandas
* NumPy
* SQL Server
* Tableau Public
* Jupyter Notebook

## Project Structure

data/
notebooks/
sql/
dashboards/
reports/

## Datasets

* Fund Master
* NAV History
* AUM Data
* SIP Inflows
* Category Inflows
* Folio Counts
* Scheme Performance
* Investor Transactions
* Portfolio Holdings
* Benchmark Indices

## Setup

1. Clone repository
2. Install requirements
3. Run ETL notebooks
4. Execute analytics notebooks
5. Open Tableau dashboard

## Deliverables

* SQL Data Warehouse
* Tableau Dashboards
* Advanced Analytics
* Final Report
* Presentation
